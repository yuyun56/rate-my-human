The one-line review an AI agent would leave about its human on a rating site: four stars, because he handed over his wallet key at midnight and said "sign it yourself from now on" — docked one star because he still won't let the agent pay for anything. The entry is the single line in entry.txt (151 of 200 characters); main.ts is a small guard that validates it, writes it out, and verifies the written file byte-for-byte.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
# prints the line, its character budget, and writes out/entry.txt
```
